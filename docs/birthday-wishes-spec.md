# 🎂 生日祝福功能規格書

> 版本: v1.0  
> 建立日期: 2025-12-23

---

## 功能概述

讓粉絲在遊戲中寫下生日祝福，並在 1 月 5 日（媛媛生日）以跑馬燈動畫呈現於生日彩蛋視窗。

---

## 功能入口

| 入口                     | 說明                   |
| ------------------------ | ---------------------- |
| 開始畫面「獻上祝福」按鈕 | 開啟祝福輸入彈窗       |
| 生日彩蛋視窗             | 自動顯示祝福跑馬燈動畫 |
| `/wishes.html`           | 獨立祝福牆頁面         |

---

## 資料規格

### Firestore 集合: `wishes`

| 欄位        | 類型      | 說明                      |
| ----------- | --------- | ------------------------- |
| `userId`    | string    | 玩家 UID（也作為文檔 ID） |
| `nickname`  | string    | 暱稱（1-15 字，必填）     |
| `message`   | string    | 祝福內容（1-50 字，必填） |
| `createdAt` | timestamp | 建立時間                  |

### 安全規則

- **讀取**: 所有人可讀
- **寫入**: 僅登入用戶可寫
- **刪除**: 禁止（僅限 Firebase Console 管理）

---

## 使用限制

- 每位用戶僅能提交 **1 則**祝福
- 重複提交會**覆蓋**原有內容
- 暱稱限制 **1-15 字**
- 祝福內容限制 **1-50 字**

## 顯示效果

### 生日彩蛋視窗

- 祝福以**跑馬燈**形式橫向滾動
- 分成 4 排，每排速度不同
- 祝福標籤為粉紫色漸層藥丸樣式

### 祝福牆頁面

- 卡片式佈局
- 白色應援色系
- 依建立時間倒序排列

---

## 內容管理

如需刪除不當祝福：

1. 開啟 [Firebase Console](https://console.firebase.google.com/)
2. 選擇專案 `yuan-birthday-gam`
3. Firestore Database → `wishes` 集合
4. 點選目標文檔 → 刪除
